# 古韵抽卡 v4.6 · 用户体验升级路线图

> **For agentic workers:** 本文件是「下一步开发计划」roadmap。各 Task 按优先级串行实施，每个 Task 独立 commit + push。
> **2026-09-04 更新**：经领主大人拍板，**诗词朗读（TTS）不在本期范围**，已从路线图移除。下方为修订后的优先级。

**Goal:** 在零依赖 / 单 HTML / 原生 ESM / 「每次换一张 ≤2 请求」的架构红线上，持续提升「一图一诗」的沉浸感与可读性。v4.6 聚焦「看得懂、记得住、留得下、更顺手」四条主线（**听** 不在本期）。

**Architecture:** 沿用 v4.5.2 全部约定（主页 `index.html` + `src/main.js`、贺卡页 `festival.html` + `src/festival-ui.js`、导出 `src/cards.js`、配图 `src/images.js`、记忆 `src/store/*` + `src/ui/*`）。新功能一律以原生 API / localStorage 实现，不引 npm、不加构建。

---

## Global Constraints（架构红线，所有 Task 隐含前提）

- **零依赖**：仅原生 ESM + DOM + Canvas + Web API，无 npm 无构建。
- **请求纪律不松动**：任何「换一张 / 换图」行为 ≤2 请求（1 次 random + 1 次图；本地优先模式 0 次 random）。新增功能**不得**引入额外网络请求。
- **localStorage 命名空间**：沿用 `pc_v3_*` 前缀；新键需进 `src/store/schema.js`。
- **视觉一致性**：米白 + 朱砂 + 衬线 + 印章色板不变；新控件复用 `.pc-btn` / `.pc-switch` 体系。CSS 实际位于仓库根目录 `styles.css`（非 `src/`）。
- **零崩溃兜底**：PWA / 复制等能力检测不可用 → 静默降级（toast 提示），绝不抛错阻断主流程。
- **Commit 频率**：每个 Task 独立 commit + push master（符合 WorkBuddy 用户偏好）。
- **测试规范**：纯 node + assert 范式；浏览器能力（安装引导 / 复制）无法 node 单测的，改用手工冒烟清单 + `node --check` 语法校验。

## Task 1: 译文·赏析（规划，高价值 · P0）

**Files:** `src/poems.local.json`（每首加 `appreciation` 字段：白话译文 + 1 句赏析）/ `src/main.js`（译文折叠区 toggle）/ `styles.css` / `README.md`

**设计**：默认「经典诗词」模式下（本地 70 首），点「赏析」展开白话译文 + 一句短评；诗泉全网模式不显示译文（无数据）。折叠区复用 `.postcard-body` 下方，入场动画不重播。

**人工环节**：70 首译文需逐首校订（可分批，先 20 首高频诗，其余逐步补全，缺失则按钮置灰）。

**约束**：纯本地数据，0 请求；字段缺失不报错。

---

## Task 2: 配图风格偏好（规划 · P0）

**Files:** `src/store/schema.js`（新键 `pc_v3_img_style`）/ `src/images.js`（`poemPrompt` 引入风格前缀）/ `index.html` + `src/main.js`（风格切换 UI）/ `styles.css`

**设计**：顶部新增一个小切换（或放进「记忆」面板设置区），选项 `国风水墨`（默认，现 prompt）/ `实景摄影` / `唯美插画`。存入 localStorage，影响 Pollinations prompt 风格词；Picsum 兜底不变。换图时即时生效。

**约束**：双源并发不变；仍是 ≤2 请求；默认态与 v4.5.2 像素级一致（不传偏好 = 国风水墨）。

---

## Task 3: 收藏整卡记住配图（规划）

**Files:** `src/store/favorites.js`（`toggle` 记录 `seed`/`imgUrl`）/ `src/main.js`（收藏后重渲染还原同图）/ `src/ui/renderers.js`（收藏列表显示缩略图）

**设计**：收藏时把当前配图的 `seed`（Picsum/Pollinations 同源可复现）与 `imgUrl` 一并写入 favorites；收藏夹点开某首时若存 seed，优先用同 seed 复现原图。容量上限 200 不变。

---

## Task 4: 每日一诗 + 打卡（规划）

**Files:** `src/store/schema.js`（新键 `pc_v3_daily`）/ 新 `src/store/daily.js`（日期 + 连续天数 + 今日诗 id）/ `index.html` + `src/main.js`（每日一诗入口 + 打卡日历微件）

**设计**：首次进入当日未抽 → 顶部轻提示「今日一诗 · 已连续 N 天」；点开看当日诗（当天固定，刷新不变）。复用本地库抽一首按日期 hash 稳定选。与 workspace `daily-checkin` 项目思路一致（本地 streak，不引后端）。

---

## Task 5: 一键复制（规划）

**Files:** `src/main.js`（复制按钮 + Clipboard API）/ `styles.css` / `README.md`

**设计**：`postcard-foot` 或操作区加「复制」按钮，复制诗词 + 译文文本（若无译文则仅诗词）。Clipboard API 不可用时降级为 `document.execCommand('copy')` 或 toast 提示。

---

## Task 6: PWA 安装引导（规划）

**Files:** `src/main.js`（`beforeinstallprompt` 捕获 + 引导条）/ `styles.css` / `manifest.webmanifest`（已存在，核对）

**设计**：捕获 `beforeinstallprompt` 事件，未安装时顶部出现轻量「安装到主屏」引导条（可关闭、localStorage 记忆不再提示）；点击触发原生安装。不破坏现有 SW 缓存策略。

---

## Task 7: 锦上添花（规划，择机实施）

- **暗色导出图**：`composeCard` 加 `options.dark = true`，导出暗色版式 PNG（色板翻转，印章朱砂保留）。
- **不感兴趣 / 同作者**：本地优先模式加「换一首同作者」；全网模式加「不感兴趣」（本次 session 去重）。
